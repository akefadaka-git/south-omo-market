# Language and localization process

Supported product languages: Amharic (am), English (en), Maale (mdy). Product is Amharic-first; English is the current implementation fallback.

Maale wording is not approved merely because a locale is registered. Before release, maintain a terminology register; obtain Maale-speaking review for marketplace, category, moderation and safety terms; record reviewer/date/decision; validate actual script and font requirements; and test approved language samples.

Do not invent Maale translations in code. Translation review is a release gate.
